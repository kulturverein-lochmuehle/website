## Basic usage

Scrolls the section after the one it stands in into view.

```html
<kvlm-section>
  <kvlm-scroll-down label="Weiter nach unten"></kvlm-scroll-down>
</kvlm-section>
```

## Custom colors

```html
<kvlm-scroll-down
  style="--kvlm-scroll-down-background-from: #fff; --kvlm-scroll-down-background-to: #ddd"
></kvlm-scroll-down>
```
